# 🚗 IBM Full Stack Software Developer Capstone Project

## 📝 Introduction
This is the final Capstone project for the **IBM Full Stack Software Developer Professional Certificate** on Coursera. This project builds a comprehensive web application for a national car dealership network called "Best Cars". 

The application allows users to:
- View a nationwide list of car dealerships.
- View specific details and customer reviews for each dealership.
- Log in or register a user account to submit new reviews.
- Utilize an automated Sentiment Analysis system to evaluate reviews (Positive, Negative, or Neutral) via a dedicated Microservice.

## 🚀 Features
- **Frontend**: A highly interactive Single Page Application (SPA) built with **React**.
- **Backend**: API handling, user authentication, and database management utilizing **Django** & **Django REST Framework**.
- **Microservices**: A dedicated Node.js/Express.js (or Flask) service handling the Sentiment Analyzer logic.
- **Containerization**: Standardized and isolated environments using **Docker**.
- **Deployment**: Cloud-ready architecture (designed for IBM Cloud Code Engine / Kubernetes).

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript, React, Bootstrap
- **Backend**: Python, Django, SQLite
- **Microservices**: Node.js, Docker
- **Version Control**: Git, GitHub
